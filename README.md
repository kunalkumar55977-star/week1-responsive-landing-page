# Week 1 Task — Responsive Landing Page Development

## Project overview
A responsive landing page for **Northstar Studio**, a fictional digital studio. The page uses semantic HTML5, modern CSS Grid/Flexbox, media queries, and vanilla JavaScript for the mobile navigation menu.

## Folder structure
```text
week1_responsive_landing_page/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Run locally
1. Extract the ZIP archive.
2. Open `index.html` in a modern browser.
3. Resize the browser or use developer tools to test desktop, tablet, and mobile layouts.

No build tools, frameworks, or external dependencies are required.

## Features
- Responsive header and collapsible mobile navigation.
- Hero section with primary and secondary calls to action.
- Feature cards, process section, about section, contact panel, and footer.
- Semantic landmarks and descriptive navigation labels.
- Keyboard skip link, visible focus behavior from browser defaults, and reduced-motion support.
- CSS variables and comments to make the design easier to maintain.

## Testing checklist
- [ ] Desktop layout (1200px or wider)
- [ ] Tablet layout (around 768px)
- [ ] Mobile layout (375px and 320px)
- [ ] Mobile menu opens, closes, and closes after selecting a link
- [ ] All section links navigate to the correct section
- [ ] No horizontal overflow at small widths

## Design note
The layout and visual direction are original interpretations of a typical landing page wireframe. The decorative hero illustration is created with CSS, so there are no image assets to manage.
